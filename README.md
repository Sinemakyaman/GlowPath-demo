# 🌐 GlowPath

GlowPath, kadınların güvenliğini artırmayı, dayanışma ağlarını güçlendirmeyi ve şiddet riskine karşı **anonim, hızlı ve güvenli bir destek hattı** oluşturmayı hedefleyen web tabanlı bir platformdur.  
Proje, kadınların acil durumda konum paylaşarak dayanışma ağına ulaşabilmesini ve destek mekanizmalarını görünür kılmayı amaçlar.

--- 

## 🎯 Proje Amacı
- Kadınların şiddet ve taciz riski altında olduklarında **anonim ve hızlı** şekilde yardım çağrısı yapabilmelerini sağlamak.  
- Kadın dayanışma ağlarını **teknoloji destekli bir platformda birleştirmek**.  
- Verileri KVKK uyumlu şekilde işleyerek güvenli bir ekosistem oluşturmak.  

---

## ✨ Özellikler
- 🚨 **Acil Destek Butonu** – Tek tıkla güvenilir kişilere/kurumlara haber verme  
- 📍 **Konum Paylaşımı (opsiyonel)** – Anonim veya izinli konum paylaşımı  
- 🤝 **Kadın Dayanışma Ağı** – Kullanıcıların birbirine destek olabileceği güvenli ağ  
- 🔒 **Veri Gizliliği** – KVKK’ya uygun, şifrelenmiş veri akışı  
- 📊 **Pilot Kullanıcı Analizi** – Google Form üzerinden geri bildirim toplama  

---

## 🛠 Kullanılan Teknolojiler
- **React + Vite** → Ön yüz geliştirme  
- **TailwindCSS** → Hızlı ve modern arayüz tasarımı  
- **Node.js (opsiyonel API)** → Backend altyapısı (planlama aşamasında)  
- **GitHub Pages / Vercel** → Web demo barındırma  
- **Gamma** → Sunum ve proje tanıtım slaytları  

---

## 🚀 Kurulum ve Çalıştırma

Projeyi kendi bilgisayarınızda çalıştırmak için:

```bash
# Depoyu klonla
git clone https://github.com/Sinemakyaman/glowpath.git

# Proje klasörüne gir
cd glowpath-demo

# Bağımlılıkları yükle
npm install

# Geliştirme sunucusunu başlat
npm run dev

Ardından tarayıcıdan şu adrese gidin:
👉 http://localhost:5173
```
